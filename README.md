# 拼团营销微服务 (Group Buy Market)

## 项目简介

拼团营销微服务是一个基于DDD（领域驱动设计）架构的营销活动管理服务，专注于拼团活动的全生命周期管理。系统采用微服务架构设计，通过领域驱动设计划分清晰的业务边界，实现复杂营销业务的高内聚、低耦合。

本服务提供拼团活动配置、规则引擎编排、用户标签管理、交易锁单、拼团结算、退款处理等核心功能，支持高并发场景下的库存抢占和分布式事务处理，是拼团营销业务的核心支撑服务。

## 系统架构

### 架构特点

- **微服务架构**：独立部署，服务间通过消息队列异步通信
- **DDD设计**：基于领域驱动设计，清晰的业务边界划分
- **高并发支持**：无锁化库存抢占，支持高并发场景
- **规则引擎**：支持规则树动态编排，灵活配置营销策略
- **分布式事务**：本地消息表+定时任务，保证最终一致性

### 核心领域

系统采用DDD领域驱动设计，将业务划分为以下核心领域：

- **活动域（Activity）**：拼团活动配置、活动生命周期管理、优惠计算
- **标签域（Tag）**：用户标签体系、人群筛选、精准营销
- **交易域（Trade）**：订单锁单、拼团结算、退款处理、任务通知

## 核心功能

### 1. 拼团活动管理

- **活动配置**：支持多种拼团模式（普通拼团、阶梯拼团等）
- **优惠计算**：支持满减、满折、直减、折扣等多种优惠策略
- **规则引擎**：基于规则树编排，支持动态配置营销规则
- **活动试算**：实时计算活动优惠，支持多线程并发查询

### 2. 用户标签系统

- **标签管理**：基于Redis BitMap实现高性能标签存储
- **人群筛选**：支持标签交集、并集、差集操作
- **精准营销**：基于用户标签进行精准营销投放

### 3. 交易锁单服务

- **无锁化抢占**：基于CAS操作实现高并发库存抢占
- **规则过滤**：活动有效性、库存条件、用户限购等规则校验
- **责任链模式**：灵活组合校验节点，支持流程可插拔

### 4. 拼团结算服务

- **自动结算**：达到成团条件自动触发结算
- **分布式事务**：本地消息表+定时任务保证最终一致性
- **幂等处理**：分布式锁保证多实例环境下的幂等性

### 5. 退款处理服务

- **策略模式**：支持多种退款场景（已支付未成团、已支付已成团等）
- **退款流程**：责任链模式实现退款流程可插拔
- **数据一致性**：保证退款数据的一致性

## 技术亮点

### 1. DDD领域驱动设计

采用DDD架构设计，将业务划分为活动域、标签域、交易域等核心领域，通过聚合根统一管理业务状态，保证数据一致性。领域事件驱动实现跨域协作，构建完整的拼团交易流程框架。

### 2. 规则树编排和责任链解耦

**规则树编排**：采用组合模式构建试算规则树，串联切量降级、策略优惠与人群过滤等节点，支持活动规则的动态编排。

**责任链模式**：抽象模板承载锁单与结算流程，涵盖活动有效性、库存条件等实时过滤，实现规则与流程低耦合、可插拔。

### 3. 无锁化高并发抢占处理

借鉴分段锁思想，对拼团锁单抢占设计无锁化方案。通过CAS（Compare-And-Swap）操作和乐观锁机制，避免传统锁带来的性能瓶颈，支持高并发场景下的库存抢占。提供恢复量机制确保异常场景下的库存回滚。

### 4. 分布式事务最终一致性

营销结算时落地本地消息任务表，异步线程池分发MQ/HTTP回调通知。定时任务+分布式锁实现多实例幂等抢占与失败重试，保证支付成功+拼团结算+业务通知的可靠触达。

### 5. 高性能人群标签系统

基于Redis BitMap承载海量用户标签，相比传统Set方案压缩空间90%，支持亿级用户实时标签查询。通过位运算实现高效的标签交集、并集、差集操作。

### 6. 策略模式实现多场景适配

基于策略模式实现多种退单和营销优惠计算业务，适应不同营销场景，满足运营策略配置。支持不同场景下的退单规则和优惠策略。
